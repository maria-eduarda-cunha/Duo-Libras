# 2. Números

### 2.1.1 Números
Cada tela apresenta um gif com um número do alfabeto

Título: Número <número_da_pagina>

- Apresentar conceito de deslizar a mão para fazer próximo número (ex 10)

- Apresentar sinal de mil, milhão e bilhão, trilhão

Apresentar conceito de posição (1º, 2º lugar)
